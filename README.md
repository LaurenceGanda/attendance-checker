# Modern Attendance Tracker

A clean, responsive attendance tracking system built with HTML, CSS, and JavaScript.

## Features

- **Modern UI**: Clean and attractive interface with smooth animations and transitions
- **Real-time Statistics**: Keep track of present, late, absent, and excused attendees
- **Search Functionality**: Easily find specific entries by name
- **Data Export**: Export attendance data as CSV files
- **Persistent Storage**: Data is stored in the browser's localStorage
- **Responsive Design**: Works on both desktop and mobile devices

## How to Use

1. Open `index.html` in any modern web browser
2. Add a new entry by typing a name, selecting a status, and clicking "Add"
3. Edit or delete entries using the action buttons
4. Search for specific entries using the search bar
5. Export the attendance data using the "Export" button

## Deployment

This is a static web application that can be deployed on any web server or hosting service. No backend setup is required.

### Deployment Options

1. **GitHub Pages**: Free hosting for static sites
2. **Netlify**: Offers free plans with continuous deployment
3. **Vercel**: Similar to Netlify with free plan options
4. **AWS S3**: Low-cost object storage with static website hosting
